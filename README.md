<h1>
  D'Borges Salgados
</h1>

<p>
  Este projeto foi desenvolvido para modernizar e agilizar o atendimento de uma salgadaria, permitindo que os clientes sejam atendidos de forma mais rápida, prática e eficiente.
</p>

<br>

<h2>
  📋 Sobre o Projeto
</h2>

<p>
  O objetivo principal é reduzir o tempo de espera e otimizar o fluxo de pedidos, garantindo que a comunicação entre o cliente e a cozinha seja direta e sem erros.
</p>

<br>

<h2>
  ✨Funcionalidades
</h2>

<p>
  📍 Cardápio Digital: Visualização rápida dos salgados disponíveis.
⚡ Pedidos Instantâneos: Fluxo simplificado para escolha e fechamento.
📱 Interface Responsiva: Funciona perfeitamente em celulares e tablets.
</p>

<br>

<h2>
  🛠Tecnologias Utilizadas
</h2>

<p>
Frontend:  Ex: React / HTML & CSS / JavaScript
Backend:Node. js / Firebase / PHP 
</p>
